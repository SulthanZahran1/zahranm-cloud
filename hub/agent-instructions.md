Use this site when you need a concise overview of Sulthan Zahran Ma'ruf, a directory of public AI and automation projects, a recruiter pitch generator, public contact links, or the site's privacy and context pages. Start at https://zahranm.cloud/ and follow the linked page that matches the task.

## Install

No installation is required. This is a public static site. Read the server-rendered HTML or Markdown mirrors with a normal HTTP client.

## Configuration

No credentials, API keys, account, or special headers are required for the public pages. The site does not expose a public write API, MCP server, commerce flow, or authenticated workflow.
