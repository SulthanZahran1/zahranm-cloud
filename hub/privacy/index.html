Privacy

scope

This privacy page describes the public hub at zahranm.cloud. Individual project sites linked from the hub may have their own behavior and privacy terms. Check the individual project before entering information there.

data collected by this hub

The hub is a static site served by nginx. It does not provide accounts, a server-side form, a payment flow, or an authenticated data store. Fonts are self-hosted, so loading a page makes no third-party font requests. The browser may keep a short-lived local cache of public blog-feed items for up to 15 minutes so the home page can render without refetching on every visit. That cache is stored in the visitor's browser and is not sent to this server.

external services

The home page itself makes no third-party requests: besides its own self-hosted assets, it requests only the public RSS feed from blog.zahranm.cloud and embeds the first-party recruiter copilot. The recruiter copilot embedded from /recruit is a separate service: job descriptions submitted to it and the pitches it generates are logged, and visitor IP addresses are stored only as hashes. To write a pitch, it sends the submitted job description to a third-party LLM API. Don't paste confidential material into it. Project links, GitHub, and LinkedIn are external destinations. Those services receive requests according to their own policies when a visitor or browser follows a link or loads a public asset.

choices and contact

You can disable JavaScript or clear local browser storage at any time. The core identity, project links, contact details, and this policy are available in server-rendered HTML and machine-readable files. For questions about this page, contact the site owner by email.
