privacy

scope

This privacy page describes the public hub at zahranm.cloud. Individual project sites linked from the hub may have their own behavior and privacy terms. Check the individual project before entering information there.

data collected by this hub

The hub is a static site served by nginx. It does not provide accounts, a server-side form, a payment flow, or an authenticated data store. The browser may keep a short-lived local cache of public blog-feed items so the latest blog teaser can render without downloading the feed on every visit. That cache is stored in the visitor's browser under the key used by the page and is not sent to this server.

external services

The page can request the public GitHub contribution graph from ghchart.rshah.org and the public RSS feed from blog.zahranm.cloud. Project links, GitHub, LinkedIn, and the recruiter copilot are external destinations. Those services receive requests according to their own policies when a visitor or browser follows a link or loads a public asset.

choices and contact

You can disable JavaScript or clear local browser storage at any time. The core identity, project links, contact details, and this policy are available in server-rendered HTML and machine-readable files. For questions about this page, contact the site owner by email.
