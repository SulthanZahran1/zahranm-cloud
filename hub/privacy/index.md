# Privacy for zahranm.cloud

## Scope

This page describes the public hub at zahranm.cloud. Individual project sites may have their own behavior and privacy terms.

## Data collected by this hub

The hub is a static nginx site. It does not provide accounts, a server-side form, a payment flow, or an authenticated data store. The browser may keep a short-lived local cache of public blog-feed items. That cache remains in the visitor's browser.

## External services

The public GitHub contribution graph, blog RSS feed, project links, GitHub, LinkedIn, and the recruiter copilot are external destinations with their own policies.
