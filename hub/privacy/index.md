# Privacy for zahranm.cloud

## Scope

This page describes the public hub at zahranm.cloud. Individual project sites may have their own behavior and privacy terms.

## Data collected by this hub

The hub is a static nginx site. It does not provide accounts, a server-side form, a payment flow, or an authenticated data store. Fonts are self-hosted, so no third-party font requests are made. The browser may keep a short-lived local cache of public data (blog-feed items for up to 15 minutes, GitHub contribution counts for up to 6 hours). That cache remains in the visitor's browser.

## External services

The home page requests public GitHub contribution counts from github-contributions-api.jogruber.de and the public RSS feed from blog.zahranm.cloud. The recruiter copilot at /recruit is a separate service: job descriptions submitted to it and the pitches it generates are logged, and visitor IP addresses are stored only as hashes. Don't paste confidential material into it. Project links, GitHub, and LinkedIn are external destinations with their own policies.
