about

focus

Sulthan Zahran Ma'ruf is an AI engineer focused on practical interfaces between people, software, and language models. This hub collects public projects, experiments, and writing in one place. The work is intentionally small enough to inspect and useful enough to try.

current work

Current work includes voice agents, agent harnesses, automation, recruiter tooling, translation, knowledge access, and operational dashboards. The projects list on the home page is the fastest way to browse the public demos. The recruiter copilot is available at /recruit.

how to use this site

Use this page for identity and context, the projects list for public destinations, and the contact page for direct communication. Agents can start with llms.txt, agent-instructions.md, or the XML sitemap. These files describe the same public information without requiring client-side JavaScript.

scope

This is a personal project hub, not a general-purpose software service. It does not offer an API, account system, paid checkout, MCP server, or automated support channel. Follow the linked project site for the capabilities and terms of each individual project.
