# zahranm-cloud

Central hub (zahranm.cloud) + WriteFreely blog (blog.zahranm.cloud) deployment.

The apex zahranm.cloud becomes the central index of all public web properties:
hand-crafted static HTML behind nginx, replacing the retired Astro portfolio.
The blog is a single-user WriteFreely instance behind Traefik.

Planning is charted as a wayfinder map in this repo's Issues. See `AGENTS.md`.
